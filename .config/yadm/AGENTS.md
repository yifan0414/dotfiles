# yadm 维护入口

先区分任务：维护仓库时修改源文件并验证；配置机器时按下面的安装流程盘点、部署和验收。仓库维护本身不触发软件安装或远端操作。

## 按任务读取

- [机器安装流程](docs/machine-setup.md)：角色选择、bootstrap、网络和 shell 配置组织的权威说明。
- [Linux 服务器](docs/dl-server.md) / [Mac 工作机](docs/mac-client.md)：按当前机器角色选择，组件规则由角色文档链接。
- [同步与凭据](docs/sync.md)：备份、加密归档和 GitHub 认证。

具体配置规则维护在对应主题文档；本文件和技能只负责入口与工作流程。

## 工作约束

- 检查已有改动，保留与任务无关的工作。机器配置沿用当前软件源、实验环境、SSH 身份和用户授权。
- 每台机器独立核对路径、账户、共享组和硬件。仅连接用户明确提供并授权的远端。
- 非敏感机器参数和配置源按安装流程纳入版本管理；本机报告、私密设置放在忽略的 `~/.config/yadm/local/`。凭据、数据集、模型和运行缓存留在仓库之外。
- 报告实际验证结果和待处理项；基础 CLI 盘点通过只证明工具齐备，组件部署和训练环境分别验收。
